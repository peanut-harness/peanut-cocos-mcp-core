# Peanut Cocos MCP Core

Open-source foundation for the Peanut Cocos MCP.

This repository is intentionally limited to public contracts, the capability policy model, and safe base execution primitives. Premium workflows, licensing, signed plans, and proprietary rule packs live in the private Pro repository.

## Status

Migration has begun from the legacy integration repository. The first public API surface is the capability policy contract; runtime extraction follows after the contract is stabilized.
