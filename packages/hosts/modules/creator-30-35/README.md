# peanut-pod-35

Creator **3.0.x–3.5.x** 薄宿主（`early3x` 产品线 MVP）。

## 边界

- Runtime 走 `adapter-35`（`supportLevel: compatible`）
- 装入工程 **`extensions/peanut-pod-35/`**
- silent-asset / lumen 须实机重测；勿与 `peanut-pod`（3.6–3.8）同名覆盖

## 打包

```bash
cd products/cocos/editor
npm run --workspace peanut-pod-35 pack
```
